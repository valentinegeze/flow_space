What this does. Bed elevations and severity are downsampled to a common — simulation grid. Each cell uses Manning's kinematic-wave overland flow (sand-bed parameters: n ≈ 0.03, infiltration ≈ 5 mm/hr) with proportional D8 routing. Burn severity perturbs per-cell infiltration (×1 − 0.70·s) and roughness (×1 − 0.15·s), the same curve mosaic-flow uses on NLCD-derived parcels. Result: where post-fire runoff concentrates is a function of the measured topography and the measured channel-persistence map — not a synthetic landscape.

Elevations are scaled by ×100 for the simulation so sub-cm bed variations produce model-meaningful slopes. Magnitudes (water-in, outflow) are illustrative; the spatial pattern of where flood depth pools is the point of interest.
